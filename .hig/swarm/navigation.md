Header and footer on this portfolio landing are quiet in-flow chrome, not an app shell: `SiteShell` renders a semantic `<header>` / `<footer>` inside `.home` with no tab bar, sidebar, or fixed toolbar. Colours are already token-driven — brand link `--ink` / hover `--accent`, contact links via `.home__link` (`--accent`, `--accent-focus-ring`), hairlines `--separator`, footer links and meta `--text-muted`; neither `app/styles/layout.css` nor `app/styles/footer.css` sets shell backgrounds or literal hex/rgb/hsl on navigation surfaces. Dark mode must not add chrome here: `prefers-color-scheme` overrides live in `app/styles/tokens.css` only; header/footer stay transparent on `--bg` with no elevated bar, blur, or dark-only borders. `viewport.themeColor` is unnecessary for the header band itself (it shares the page surface); if browser UI tint is desired, that belongs on the `Viewport` export in `app/layout.tsx` — conflict with branding register if another worker owns that file; do not duplicate from this surface.
